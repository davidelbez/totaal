# Release notes

> Starter skill from Totaal, adapted to {{ORG}} at setup. It is meant to change: every correction and every new habit of the team becomes a rule here (evening tuning).

## Inputs
- merged changes and closed tickets since the last release
- register lines they resolve

## Steps
1. List what shipped as two plain lists: features and fixes.
2. Name the accounts that asked for each item.
3. Write the client-facing version separately, without internal words.
4. Update the register lines' status.

## Output
Team notes + client notes + register updates.

## Rules
- No internal jargon in client-facing notes. → [[hard-rules]]
