# Bug report

> Starter skill from Totaal, adapted to {{ORG}} at setup. It is meant to change: every correction and every new habit of the team becomes a rule here (evening tuning).

## Inputs
- the ticket(s), screenshots, the requester's environment
- the product-feedback register (search for duplicates)

## Steps
1. Search the register and the tracker for an existing report.
2. Write steps to reproduce, expected, actual, impact, accounts affected.
3. Propose it as a recommended task for the product owner.
4. Link it from the register line.

## Output
Bug report text + register line + recommendation.

## Rules
- Search before writing: one fact, one line. → [[product-feedback]]
- No end-user names in the report. → [[hard-rules]]
