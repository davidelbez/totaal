# Monthly admin

> Starter skill from Totaal, adapted to {{ORG}} at setup. It is meant to change: every correction and every new habit of the team becomes a rule here (evening tuning).

## Inputs
- the checklist page in the wiki (create it on first use)
- ~~email, ~~calendar, ~~shared drive

## Steps
1. Read the checklist; for each item, prove it done with a tool or mark it pending.
2. List what is late with its owner.
3. Propose additions to the checklist from what came up this month.

## Output
Checklist status with proofs + recommended tasks.

## Rules
- Done means proven in the tool, not remembered. → [[how-we-work]]
