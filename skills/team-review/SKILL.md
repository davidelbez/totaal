# Team review — every two weeks

Neutral by design: facts before feelings, no judgement of people, a stated error is an asset. Personal matters go to one-on-ones, never to this page.

## Before the session (Claude prepares)
Create `notes/YYYY-MM-DD-team-review.md`:
1. **Daily commitments** — pre-filled continuously from internal meeting transcripts (never recaps): each commitment as done / in progress / not done. The session only rules on items already traced.
2. **Previous decisions** — each with a completion score (done / partial / no) read from the ~~task tracker status, not from memory.
3. **Improvement areas** — empty, ready for DESC.
4. **New decisions** — empty table: decision · owner · deadline.

## DESC (for each improvement area)
- **Describe** the observable fact, without judgement.
- **Express** the concrete effect it has on the work or the team.
- **Specify** what to change.
- **Consequences**: what changes once it is done, with the decision's owner and deadline.

## After the session
- Every actionable decision becomes a task prefixed `[Review YYYY-MM-DD]`: in the task tool (the source of truth) and mirrored on the review page. Permanent rules and decisions applied on the spot create no task — they go to the relevant skill or wiki page (three writes).
- Unfinished past decisions are either decided again or explicitly dropped.
- Link the review from the previous one and from `concepts/how-we-work.md`.
