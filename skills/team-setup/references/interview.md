# Setup interview — full question set

Ask only what changes what you build. Prefill from connected sources (signature, CRM company record, website) before asking.

## Company
- Name used with clients (and names never to use externally).
- What you sell, to whom, the price model in one line.
- Your 3 strongest proof points (figures you may quote externally).
- Lifecycle of an account: how it starts, how it is delivered, how it renews.

## Team
- Members: name, role, scope, manager. Who is the lead (arbitration owner)?
- How many people will use it? Up to ~5 → simple mode; more → team mode.
- Rituals: daily, weekly, review every two weeks?
- Language with the team; language and formality with clients.

## Tools (one per category; "none" is an answer)
| Category | Question |
|---|---|
| email | Which mailbox? Shared inboxes? |
| calendar | Which calendar holds client commitments? Any booking tool? |
| chat | Which tool? Which channels matter? |
| CRM | Which CRM? Who owns the pipeline? |
| task tracker | Where do tasks live (CRM tasks, a tracker, nowhere)? |
| meeting recorder | Which recorder or transcription tool? Where do transcripts land? |
| ticketing | Support inbox or helpdesk? |
| shared drive | Where do contracts, decks, exports live? |
| BI / product analytics | Where do the numbers come from? |
| other | Any system of record a person checks daily? |

## Hard rules (never guess these)
- Customer-facing naming, official figures, security constraints (identity provider, data location), legal wording, signature.

## Recurring work (for the first company skills)
- Which 3–5 tasks come back every week and take the most time?
- For each: who does it, from which sources, what does a good result look like (an example)?
