# Routines index

> Every scheduled task of the company. Cloud by default. Space tasks at least 15 minutes apart: the app may run only a few scheduled tasks at once and skip the others silently.

| Routine | Who | When | Where it runs | Trunk |
|---|---|---|---|---|
| Daily arbitration (team mode) | one owner | weekdays, before the team starts | cloud | [[arbitration]] |
| Morning routine | each member | weekdays, early | cloud | [[morning]] |
| Evening tuning | one owner or each member | weekdays, evening | cloud | [[tuning]] |
| Weekly hygiene (simple mode) | one owner | weekly | cloud | [[weekly-hygiene]] |
| Product-feedback synthesis | one owner | weekly | cloud | [[product-feedback-weekly]] |
| Onboarding check-ins | per newcomer | day 1, 7, 30 | cloud | [[onboarding-checkins]] |
| Browser steps (tools with no connector) | per member | as needed | on the member's computer | the skill concerned |
